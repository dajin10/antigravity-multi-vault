1. 动态注册表 (N-Slot)

废弃硬编码 A/B/C/D，改用 registry.json 存储任意数量仓位、别名与角色，支持旧版四仓一键无损迁移。

2. 空白沙盒无痛加号

新增账号时自动暂存当前会话到 restore_backups/，登录新号捕获完成后即可秒切回主力仓。

3. 清晰额度自主切换

实时展示每个仓位 5h / 每周剩余百分比与恢复倒计时，由用户自主点击切换，无多余弹窗打扰。

4. 开源零入侵 & 隐私安全

纯 Python 标准库跨平台实现（Win/Mac/Linux），支持 --mask 与 UI 一键屏蔽邮箱，零云端上传。
